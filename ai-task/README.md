# Qualix AI 自主任务

AI 编排中的独立截图执行方式，使用 Vue / TypeScript 实现，使用统一的任务首页、圆角工作区与底部对话输入区。在新建区域选择自主任务后执行，工作区共用一个对话区；打开历史对话自动恢复任务类型。主区域实时展示操作、AI 发现、计划进度和执行结果；设备预览可通过历史对话旁的共用按钮打开可拖动的悬浮窗口，流程编排与自主任务均可使用，关闭后停止浏览器取图。队列、笔记和录像使用工作区内的直接入口。每轮固定发送设备截图。与流程编排的数据和界面状态独立。

- Flash 快速观察与执行；Pro 先维护测试结果目标，再按截图证据推进计划。
- 以所选 App 包名限定任务范围。前台切到桌面或其他应用时停止，不点击其他 App 图标，也不在其他应用中输入；Android 系统权限弹窗可继续处理。
- 不读取组件树，不使用 Appium 定位器、节点或脚本。只执行校验后的截图坐标、输入、滑动、按键和等待。
- 每轮记录实际模型返回、原生思考内容、发送的提示词及图片引用，历史中以“用时”展开查看模型返回的思考。
- 任务、对话、计划、笔记、截图及录像索引独立于 Appium 方式。继续发送要求、重命名、删除历史均只影响自主任务。
- 模型连接及图片输入验证通过后才启动 App 和录屏。动作结果不确定时不自动重发；重复无效操作、连续无效决策和执行预算均有停止保护。
- 同一设备的自主任务、Appium 编排/回放和官方 Midscene 实际操作共用设备锁。页面切换不终止后端任务，停止需通过任务操作执行。
- `.midscene-app/ai-autonomy.sqlite` 保存记录，`ai-autonomy-images` 保存截图；官方 Midscene 页面单独使用自己的服务和浏览器存储。
