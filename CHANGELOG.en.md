## [0.1.9]

- Supports inserting operations anywhere in the process and editing nodes, locators, timeouts, and input content.
- Supports Activity jump detection and single Activity script recording protection.
- Supports connecting saved scripts and combining login, homepage and other cross-page testing processes.
- Added a new script management list to load, delete and play back recorded scripts.

## [0.1.8]
- Added selector uniqueness detection and parent context positioning to solve the problem of multiple components sharing the same ID.
- Playback supports multi-level positioning and coordinate retrieval, and records page checkpoints and complete failure diagnostic information.

## [0.1.7]
- If there is a new addition, click, enter, clear, return and other optional operations.
- Added waiting and condition capabilities such as waiting to appear, judging existence, and waiting to disappear.

## [0.1.6]
- Added a new reusable device preview that supports clicking on the screen to select component tree nodes and refreshing the real-time screen.
- The component tree supports scrolling and displays the current activity.
- The recording operation is selected through the "Add Operation" menu.

## [0.1.5]
- For the first time, Appium model-free recording and playback capabilities are provided.
- Supports recording clicks, inputs, assertions, and delays from the component tree and saving them as replayable scripts.
- App package names and default apps in Settings are managed uniformly.
